# Al Manara Academy & Mosque

Official website for Al Manara Academy & Mosque, Ballwin, Missouri (masjidalmanara.com).

A static, multi-page website built with **HTML5, Tailwind CSS (CDN), and Vanilla JavaScript**. No build step and no server-side code — open `index.html` in any browser or host it on any static host (GitHub Pages, GitLab Pages, Netlify, etc.).

## Design

iOS emerald-glass design system:

- Dark emerald gradient canvas (`#0B251C` → `#123C2E`)
- Frosted glassmorphism cards (backdrop blur + soft `rgba` borders)
- Mint (`#D1E7DD`) body text and gold (`#D4AF37`) accents
- Inter + Sora fonts, 24px radii, soft glow shadows
- Desktop navbar with dropdown menus, mobile bottom dock, and slide-down menu

## Features

- **Live prayer times** for Ballwin, MO — computed client-side (ISNA/degree math) with an online API fallback
- **Live countdown** to the next prayer, ticking every second
- **Hijri + Gregorian dates** via the `Intl` API (Umm al-Qura calendar)
- **Active-navigation highlighting** across all 16 pages, including expanded mobile groups
- Dashboard-style homepage: prayer widget, mission, quick links, and donation tiles

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Building on the site

The site was generated by a small Python build system that lives outside this repo (`/tmp/opencode/chrome.py`, `pages.py`, `build.py`). It assembles the shared header/footer/dock and all page bodies into the static HTML above. The checked-in `*.html`, `css/`, and `js/` files are the deployable artifact — nothing needs to be built at deploy time.
